# 👋 Welcome to TeamAudiyo

Founded in 2026, TeamAudiyo is an American machine learning company dedicated to building open-source audio models and inferencing engines. We bridge the gap between generative audio and autonomous agents, creating tools that enable machines to listen, generate, and interact with sound in real-time.

## 🚀 Flagship Projects

### [Audiyo](https://github.com/TeamAudiyo/Audiyo)
> The full fine-tuning and inferencing engine for audio and music models.

Our core engine supports an ever-growing list of music and audio architectures. It is designed for both research-scale fine-tuning and production-grade inference.
- ⭐ **Star this repo** to get notified about the latest releases!
- 🏷️ *Text-to-Audio | Apache-2.0*

### [Jolly](https://github.com/TeamAudiyo/Jolly)
> A lightweight, terminal-native 3D physics simulator for robot arms built for LLM agents.

Jolly provides a fast, headless simulation environment specifically designed to train and evaluate multimodal agents that manipulate physical objects.
- 💻 Terminal-native & lightweight
- 🦾 Built for LLM agent integration
- 🏷️ *Python | Apache-2.0*
